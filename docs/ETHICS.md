# Ethics, compliance & “don’t be cringe” policy

This repo is meant for **research and developer education**.

**You are responsible** for complying with:
- Site Terms of Service (ToS)
- robots.txt (when applicable)
- local laws and regulations
- privacy policies and data protection rules (GDPR/CCPA/etc.)

## Practical rules of thumb

1. **Public data only**
   - Don’t collect private or paywalled content.
   - Don’t attempt to bypass authentication or access controls.

2. **Minimize personal data**
   - Avoid collecting sensitive personal data.
   - Don’t store personal identifiers unless you have a lawful reason.

3. **Respect rate limits**
   - Don’t hammer sites.
   - Use caching + deduping.

4. **Use citations**
   - Make the model cite sources for claims.
   - Treat “answer engines” as *inputs* with citations — not a magical oracle.

5. **Safety first**
   - If a prompt looks like it’s requesting wrongdoing (exploitation, doxxing, fraud),
     do not run it.

## Sponsor-safe on-screen disclaimer idea

> “This demo uses public web sources. Always respect site ToS and privacy rules, and only collect data you’re allowed to access.”
